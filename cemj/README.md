# CEMJ（仮称）：中古語の統語コーパス（試験公開）

言島（Kätö nö Sıma）の下位コーパス．中古語の散文に，形態素と統語構造（句構造の木）を付ける．
検索画面：<https://anti-tail.github.io/LexicaJaponesicaAperta/cemj/>

**ご注意．** 木は形態素解析と規則から自動で作った下書きで，まだ査読していない（人が確かめた木は 2 文）．
主語・目的語の認定，連体修飾節の内外，引用の範囲，文の切れ目には誤りが多く含まれる．規則が推定で決めた箇所は `*.review.tsv` に理由つきで挙げた．
研究に使うときは当たった例を必ず本文で確かめ，件数をそのまま論拠にしないこと．データは作業中で予告なく変わる．
文の番号（`s0001`）は版ごとに変わる．箇所は丁・行か形態素の番号（`tkt.mutou.m000001`．固定）で示すこと．

Experimental release. The trees are generated by rules from a morphological analysis and have not been reviewed
(only 2 sentences have been checked by hand). Verify every hit against the text.

## 注釈の要点

- 空範疇（省略された主語の *pro* など）は立てない．
- 節のラベルは NPCMJ（IP-MAT，IP-ADV，IP-REL，IP-EMB，IP-NMZ，CP-THT，CP-QUE，CP-FINAL，FRAG …），語のラベルは ONCOJ に合わせた．
  ONCOJ に無い品詞は NPCMJ から取る（VB2 補助動詞，ADJN 形状詞，PNL 連体詞，CONJ，NPR）．
- 木に書く機能は SBJ・OB1・OB2・PRD だけ．ほかの役割は助詞と動詞の意味から計算する．
- て・ば・ど は独立の接続助詞 P-CONN（ONCOJ では活用語尾）．活用形はラベルに入れず，形態素の層に持つ．
- 長い節の連鎖は一文とする（接続助詞で切らない）．
