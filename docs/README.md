# 言島 Kätö nö Sıma — ONCOJ の上代語検索

<https://anti-tail.github.io/LexicaJaponesicaAperta/> で公開している検索画面．`index.html` 1 ファイルにデータを埋め込んであり，サーバーは要らない．
スマートフォンでも使える．英語版は <https://anti-tail.github.io/LexicaJaponesicaAperta/en/>．

転写の読み方と，ONCOJ と中納言のちがいは解説のページにまとめた：<https://anti-tail.github.io/LexicaJaponesicaAperta/guide.html>
ONCOJ と『日本語歴史コーパス』奈良時代編の形態論・統語論の注釈の対照は付録にまとめた：<https://anti-tail.github.io/LexicaJaponesicaAperta/appendix.html>（英語版 <https://anti-tail.github.io/LexicaJaponesicaAperta/en/appendix.html>）

意見・要望・不具合・データの誤りは，画面右上の「意見を送る」から送れる．GitHub の Issue になる．

- 用例検索：`pos#VB in#REL`，`lemma:-ki-`，`ka *{0,3} mo` のような語の並び，`IP-REL <- #VB+ADN` のような TGrep2 風の構造，転写，万葉仮名の原文で探せる
- 検索式の読み下しと，条件に当たるタグ・見出しの数をその場で表示する．属性・タグ・見出しは入力の途中で候補が出る
- ことばで探す：「関係節の中の動詞の連体形」「係助詞を含む主節で連体形で終わる」のような日本語や，「属格主語」「被枕」「係り結び」「他動詞文」「受身文」「疑問文」のような名前のある構文，pito no／ヒとのコ のような上代語の語形で探せる．英語版では verb inside relative clause のような英語も使える．読み取った構造検索の式も出る．資料は複数選べる
- 見出し語の用例：「見出し語で用例」欄に語形・語釈・番号を打って選ぶと，その見出しの用例だけを出す．複合語の見出しでもよく，語形・品詞・単独か複合語の部分かで絞れる．`#lem=L050083` のような URL で直接開ける
- 名前のある構文のうち係り結び・属格主語・疑問文・条件文は，検索の後に出るチェックで OR の範囲を切りかえられる．「または」「あるいは」で任意の OR もでき，構造検索では関係の OR `|` と式の OR `||` が使える．構造検索の `A <= B`（A が B で結ぶ．後ろに付く かも・と・や などは除いて見る），`A <<= B`（B が A の述語・中心の語），`A <+ B`（B が A の末尾に付く助詞），`A <<~ B`（B が A と同じ節の中にある）で，結びや述語を直接指せる．集計の「節の項の型」で，当たった節の項と標示の型（SBJ:ga OB1:wo VB など）ごとに数えられる
- 構文目録：上代語の文法書・論文にある構文約 410 項目を，ONCOJ の木での定義・出典・件数とともに分類して示す．名前・説明・出典で絞り込め，名前はことばで探す欄にそのまま書ける．定義できない構文は理由を示す．追加や修正は「構文の追加を申請」から GitHub の Issue として送れる．構文目録の「文献」の欄から，参照すべき文献を Issue で紹介できる
- 表記で絞る：どの検索でも，結果の上で式の要素ごと・位置ごと・当たりの範囲のすべての語について，仮名・音仮名・訓仮名・表語・地名の慣用表記・読み添えを選んで絞れる．当たりの語は表記で色分けする
- 構造の型と範列：具体的な語の並びが ONCOJ の木で `PP-SBJ{NP{N} P-CASE-GEN}` のようにどう書かれているかを数え，各位置に立つ品詞・見出しの分布を示す．型はそのまま構造検索の式になり，同じ形の箇所を過不足なく当てる．「例から式を作る」で語ごとに残す条件を選べる
- 「タグを調べる」：成分ごとのタグの意味，親・子の分布，内部構造の型，見出し語を示し，そこから検索式にタグや関係を入れられる
- タグの一覧，成分，親 × 子の出現数を数えた入れ子の表，データの形の説明
- 活用型・自他・地域・関連語つきの見出し語一覧

非公開側の言島 `build_corpus_search.py --public` が作る．権利上公開できない資料は，データも画面のコードも含めない．書き出すときに自動で検査し，痕跡があれば書き出さない．

## ONCOJ からの変更

- データは ONCOJ の検索画面から 2026-11-18 に取った作業データ（5,031 歌．TGrep2 で全件を当てて bracket 形式で書き出したもの，辞書は辞書検索で全件を出したもの）．2021.12 リリース（4,992 歌）からは，歌経標式の 40 首（KH）の追加，N-DVB → DVN，NP-PTH-OB1 → NP-OB1-PTH のような機能タグの順序，na…so の na を ADV・so を P-FNL-PHB とする分析，関係節などの痕跡 `*T*` の追加など，注釈が大きく改められている．
- 構文木は psd 形式から読み，見出し番号のノードを上の品詞ノードにたたみ，PHON・LOG などの表記ノードを語の属性にした．
  ラベル・見出し・音形・表記といった注釈の中身は変えていない．
- 有杼 aredo＝LOG are＋PHON do のように一語が表語表記と表音表記にまたがるものは 1 語とし，音形をつないだ．
- 品詞ノードの下に見出し番号が二つ以上直接並ぶもの（`(N (L050034 (LOG yama)) (L031788b (LOG mori)))` のような，全体の見出しのない複合語など．34 箇所）は，たたまずに，それぞれを品詞のない語 `?` とした．
- タグの日本語の説明は ONCOJ の凡例，つまり Grep/TGrep2 ページの一覧の訳．凡例にない成分は用例からの推定で，画面でその旨を示す．痕跡 `*T*` はラベル `*T*` の節点とし，木の中でそれがある位置に置いた（構造検索では `*T*` とそのまま書ける．`. .. , ,,` の語順の関係でも前後に数える）．
- 辞書の かな・意味・アクセント語類・用法 も見出しの詳細に示す．
