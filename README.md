# Lexica Japonesica Aperta

[Lexica Japonesica](https://github.com/anti-tail/LexicaJaponesica)（Japonesian 諸語の比較語彙データベース，非公開）のうち，
権利上公開してよい部分を出すリポジトリ．中身は非公開側の `tools/export_aperta.py` が書き出す．

The public part of Lexica Japonesica, a comparative lexical database of the Japonesian (Japonic) languages.
Everything here is generated by `tools/export_aperta.py` in the (private) main repository
(`docs/` by `build_corpus_search.py --public` of 言島 Kätö nö Sıma).

**検索画面 / Search interface:** <https://anti-tail.github.io/LexicaJaponesicaAperta/>（スマートフォン可 / works on mobile）

## 中身 / Contents

| フォルダ | 中身 | ライセンス |

| [`oncoj/`](oncoj/) | Oxford-NINJAL Corpus of Old Japanese（ONCOJ 2021.12）を CLDF（Dictionary モジュール）に書き換えた上代語のデータ：見出し語 5,871，語釈 6,190，歌 4,992，語 117,388 | CC BY 4.0 |

いま公開しているのは ONCOJ 由来のデータだけである．県別方言辞典・おもろさうし・時代別国語大辞典などの本文や，
ライセンスが確かめられていない資料に由来するデータは含めない．

At present only data derived from ONCOJ are published. Data derived from copyrighted dictionaries or from sources
whose licence has not been confirmed are not included.
